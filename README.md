# Forma

Forma is a local-first desktop workspace for Markdown Notes, structured Pages and databases. Alpha 1 is version `0.1.1-alpha.1`.

## Platform support

Alpha 1 provides macOS Apple Silicon and Windows x64 packages. Windows remains experimental and has not been natively tested. The macOS DMG is not notarised, and the unsigned Windows installer may prompt a Microsoft SmartScreen warning.

## Features and documentation

Database V2 includes Table, Board, Gallery and List views. See the [roadmap](ROADMAP.md) for the Alpha 1 feature overview and future direction, and [known issues and testing status](KNOWN_ISSUES.md) for limitations and verification details.
